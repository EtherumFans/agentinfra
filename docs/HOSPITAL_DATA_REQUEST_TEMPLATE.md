# Hospital Pilot Data Request Template

**版本**: v1.0-pilot
**日期**: 2026-05-12
**用途**: 医院试点所需数据清单及格式说明
**接收方**: 医院信息科 / 病案室 / 医保办

---

## 概述

为推进 iCoDer 智能编码审核系统在医院试点部署，需院方提供以下临床数据进行系统校准和评估。所有数据均需 **脱敏处理** —— 移除患者姓名、身份证号、住院号、电话号码、家庭地址等个人身份信息。

---

## 数据提交清单

### 1. 脱敏病案首页

| 属性 | 说明 |
|------|------|
| **优先级** | P0 — 必须提供 |

## 数据提交方式

1. 所有文件按类别命名，如:
   - `[医院名称]_病案首页_202605.xlsx`
   - `[医院名称]_出院小结_202605.json`
   - `[医院名称]_DRG分组_202605.csv`

2. 打压缩包: `[医院名称]_Pilot数据_20260512.zip`

3. 通过医院内部安全文件传输通道提交，或上传至指定的安全共享目录。

4. 数据提交前请信息科确认脱敏完整性。

---

## 数据使用承诺

- 所有数据仅用于 iCoDer 系统校准和试点评估
- 不在互联网环境传输
- 试点结束后，院方可要求删除所有原始数据
- 系统训练/校准不依赖可识别个人身份的数据
