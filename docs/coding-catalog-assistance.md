# 编码字典辅助

自建智能体详情的设置中启用“编码字典辅助”，保存草稿后生效。适用于主要诊断、其他诊断、主要手术、其他手术四类 JSON 输出。默认关闭，不改变预置智能体的受控运行路径。

配置值为 `coding_catalog_assistance: cn-catalog-assistance-v1`。运行包绑定 `icoder-cn-runtime-2026-08-27.2` 字典版本，版本进入草稿指纹及发布快照；配置改变后原评测不能用于新草稿发布。

检索只读取本次输入，不读取评测答案。按名称匹配和双字索引筛选候选，再进行模糊排序；诊断与手术分别最多 60 个候选，最多处理 16000 字符。候选可能不完整，命中不代表患者具有该诊断或已接受该手术。

同步与流式运行均先取得完整结果，再输出。结果保留原编码与组合符号，不进行截短、替换或删除；`raw.coding_validation` 记录目录收录检查，不等同于临床正确性判断，也不替代严格评测。字典版本不匹配时不会调用模型。

已安装目录含 39756 个诊断编码、28394 个手术编码。该目录为本地开发资产，不能据此宣称已匹配医院正式使用版本。训练样例仅用于调试，发布验收仍需独立数据与专业复核。
