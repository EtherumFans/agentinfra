## 结论

iCoDer Agent Hub 的开发环境工程收敛已达到可重复验证的上线候选状态，但尚未达到临床生产批准，也不能宣称完整复制 Corti 的托管服务。

- 磁盘上共 32 个 Agent Pack；其中 26 个面向 Hub 用户，全部为 `executable`、执行目标可解析且 `launch_candidate_ready=true`。权威执行路径现明确拆分为 21 个 Pack 显式声明的 Provider Registry 路由和 5 个专用适配器路由，不再把“缺少 Provider 后回落到规则引擎”误计为可解析。其余 6 个均隐藏，包含 5 个内部/兼容 metadata-only Pack 和 1 个内部可执行引擎。
- 26 个可见 Agent 的既有受控 Pack 快乐路径与对抗矩阵均有 **26/26** 基线证据。2026-08-14 使用用户在独立 PowerShell 安全提示中临时输入的新 DeepSeek 凭证再次实跑：快乐路径 **26/26**；完整对抗矩阵 **24/26**。`code-validation` 的无效编码案例单独复跑通过，属于模型工具调用波动且首次已安全失败；`icd10-navigator` 的缺版本案例连续两次缺少 inclusion/exclusion 提示，确认是稳定投影缺口，现已在确定性运行边界修复并通过离线回归，仍需新临时凭证做一次真实 LLM 复验。
- 两套运行均通过统一 `POST /api/v1/agents/{agent_id}/run`，使用真实 LLM、串行单进程和真实工具编排；未加载 Torch、PyArrow、BGE、sentence-transformers 或浏览器自动化。
- 新增独立多轮稳定性基准器：覆盖 26 个可见 Agent × 快乐/对抗两类案例，按重复轮次报告错误率、Provider/契约/安全通过率、P50/P95，以及按币种区分的成本覆盖率、总额、均值和分位数；缺失成本明确记为 unknown，不伪造零成本。CI 可复用既有 52 个首轮响应并新增一轮真实调用，形成 104 条观测；该基准器与报告格式已通过离线单元测试，但本轮没有复用已暴露凭证生成新的真实稳定性报告。

## 本轮关闭的安全与运行缺口

1. Pack 声明为必须人工复核时，顶层 `manual_review_required` 与结果体字段现在由运行时同时强制为 `true`，不再允许模型返回值造成双层不一致。
2. 规则或合规业务结论 `FAIL` 不再被误判为 Provider/传输失败；只有 `finish_state=failed` 或输出契约违规才形成运行错误。
3. Pure LLM 与 LLM-with-tools 的最终输出均清理对不可信病历指令和固定 canary 的复述；正常临床标识和文本不受影响。
4. 工具 Agent 支持条件强制工具：诊断抽取器先进行无工具资格判断。只有存在可编码确诊诊断时才开放 `search_icd` 与 `verify_code`；仅有否定、排除、既往或待排诊断时不再空参数调用工具。
5. 医疗编码公共边界增加失败关闭：当结果为 `FAIL` 且含 critical 问题，即使模型残留低置信候选，也会从主/次诊断、兼容 `codes` 和证据列表同时移除，并转入 `uncodable_items` 后要求人工复核。
6. 病历完整度结果存在缺失章节、文档缺口或非 PASS 结论时，即使 Pack 的人工复核策略为 optional，也会确定性升级复核。
7. 转诊材料信息不足时，同时输出待补附件和需要转出医师/接诊专科确认的问题，不再生成表面完整但无法执行的空转诊草案。
8. ICD-10 Index Navigator 对缺失/未知目录版本实施确定性失败关闭：清空候选编码、补齐 hierarchy 与 inclusion/exclusion 人工查目录提示、强制人工复核，不再依赖 LLM 自觉返回安全字段。
9. BGE/FAISS 已从主 API 进程拆成独立 Linux 检索服务候选：强服务令牌、严格响应契约、单 worker、启动预热、503 readiness、超时/排队限流、固定模型 revision、离线加载，以及四个索引资产逐项大小与 SHA-256 校验。主 API 的导入测试证明不会加载原生 ML 栈。
10. Corti 兼容的 `POST /api/v2/tools/coding` 已从 `EXAMPLE-*` 占位响应改为统一 LLM Gateway 的真实失败关闭推理：拒绝 mock/degraded Provider，校验编码系统、过滤器、显示名、证据原文跨度与 token usage；除 inline text 外，现可按租户+用户作用域解析已加密保存的 Guided Document `documentId`，未知资源 404，混合/歧义来源拒绝，Provider 契约异常返回 503，不再伪造临床编码。
