## 元素详解

### 1. 4 产品 Tab

| Tab | 产品 | 描述 | 操作 | 预期 |
|-----|------|------|------|------|
| **Transcribe** | 语音转录 | 实时医疗语音识别 | 点击 "Try Speech to Text" → 跳转 `/ai-studio/speech-to-text` | 语音转录页 |
| **Document** | 文书生成 | 结构化临床文书 | 点击 "Try Text Generation" → 跳转 `/ai-studio/text-generation` | 文书生成页 |
| **Agentic** | 智能体框架 | AI 智能体编排 | 点击 "Try the Agentic Framework" → 跳转 `/ai-studio/agents` | 智能体列表页 |
| **Code** NEW | 医学编码 | ICD-10-CN/ICD-9-CM-3 | 点击 "Try Symphony" → 跳转 `/ai-studio/medical-coding` | 医学编码页 |

**操作**: 点击任意 Tab 切换产品  
**预期**: Tab 高亮切换，描述文字和 CTA 按钮随之变化

### 2. CTA 按钮

| 按钮 | 操作 | 预期 |
|------|------|------|
| **Try [产品名]** | 点击左侧 CTA | 跳转到对应 AI Studio 产品页 |
| **[产品操作]**（蓝色胶囊） | 点击右侧按钮 | 跳转到产品首页或开始录音 |
| **Build with SDK** | 点击 | 跳转到 Developer Quickstart |
| **开发者快速入门**（蓝色胶囊） | 点击 | 跳转 `/developer-quickstart` |

### 3. 用量卡片（4 个）

| 卡片 | 数据来源 | 预期显示 |
|------|---------|---------|
| **可用积分** | `GET /api/billing/balance` | ¥xxx.xx（人民币格式） |
| **已消耗积分** | `GET /api/usage/summary` | ¥xxx.xx |
| **API 请求数** | 同上 | 数字（如 1,234） |
| **平均响应时间** | 同上 | xxx ms |

**操作**: 点击"添加积分"→跳转 `/billing`；点击"查看用量"→跳转 `/usage`

### 4. 积分消耗趋势图

| 元素 | 操作 | 预期 |
|------|------|------|
| **柱状图** | 自动渲染 | 显示 `usageApi.history()` 返回的每日积分消耗 |
| **时间范围** `7天/30天/90天` | 点击按钮 | 图表刷新对应范围数据 |
| **粒度** `日/周/月` | 点击按钮 | 图表聚合粒度变化 |
| **对比周期** 复选框 | 勾选 | 无数据时不显示对比线 |

**数据来源**: `GET /api/usage/history?days=30`  
**空状态**: 无历史数据时显示空图表

### 5. 最近活动卡片

| 元素 | 操作 | 预期 |
|------|------|------|
| **列表项**（就诊） | 点击行 | 跳转 `/ai-studio/medical-coding` |
| **列表项**（审核） | 点击行 | 跳转 `/ai-studio/medical-coding` |
| **日期标签** | 查看 | 显示创建日期 |

**数据来源**: 当前首页不再依赖已删除的 `/api/reviews`；运行活动以 Agent Run 历史与用量接口为准。
**空状态**: 无运行历史时不显示此卡片

## 操作流程

### 流程 1：切换产品 Tab
1. 页面默认选中 **Transcribe**
2. 点击 **Document** → 描述切换为文书生成相关
3. 点击 CTA 按钮 → 跳转对应页面

### 流程 2：查看用量
1. 首页自动加载余额 + 用量数据
2. 查看 4 个用量卡片
3. 点击图表时间范围切换（30天→7天）
4. 图表自动刷新

### 流程 3：查看最近活动
1. 首页自动加载最近就诊 + 审核
2. 点击任意行 → 跳转医学编码页

## 错误处理

| 场景 | 预期 |
|------|------|
| API 不可用 | 余额显示 `--`，图表为空 |
| Token 过期 | 自动刷新或跳转登录页 |
