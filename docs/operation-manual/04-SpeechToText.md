# SpeechToTextPage

**路由**: `/ai-studio/speech-to-text` | **定位**: 语音转录

## 元素
| 元素 | 操作 | 预期 |
|------|------|------|
| 语音转录标题 + 识别引擎 | 选择 Medvoice/Web内置 | 切换 STT 引擎 |
| 转录文本区 | 查看 | 显示 `transcript` + `interim`（灰色） |
| 空状态 | 查看 | "点击麦克风开始录音" |
| 录音按钮（蓝色胶囊） | 点击 | 开始/停止录音，录音时变红 |
| 麦克风源选择器 | 点击 | 下拉：Web内置/Medvoice |
| 转录开关 | 点击 | 显示/隐藏转录文本区 |
| 指令栏 | 查看 | 5 条指令：跳转段落/撤销/插入模板/新建段落/句号 |
| + 按钮 | 点击 | 打开添加指令模态框 |
| 设置面板 | 查看 | 听写语言/标点/暂态结果/语音指令 |
| 代码面板 | 查看 | JS/Python/C#/JSON SDK 代码 |
