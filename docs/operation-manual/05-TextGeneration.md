# TextGenerationPage

**路由**: `/ai-studio/text-generation` | **定位**: 文书生成

## 元素
| 元素 | 操作 | 预期 |
|------|------|------|
| 模板选择按钮 | 点击 | 打开模板选择模态框 |
| 模板搜索 | 输入 | 按名称/分类筛选 |
| 新建模板 ✏ | hover 行 → 点击 | 打开模板编辑器 |
| 删除模板 🗑 | hover 行 → 点击 | 内联确认按钮 |
| 输入 textarea | 输入文本 | — |
| 输入类型选择 | 点击按钮 | 字符串/自由文本/对话转录/结构化事实/JSON |
| 生成文书 | 点击 | LLM 生成结果 |
| 输出区 | 查看 | 只读卡片 + 复制按钮 |
| 设置面板 | 查看 | 模板/输出语言/文书名称/质控模式/护栏 |
| 代码面板 | 查看 | SDK 代码 |
