# FactExtractionPage

**路由**: `/ai-studio/fact-extraction` | **定位**: 事实提取

## 元素
| 元素 | 操作 | 预期 |
|------|------|------|
| 使用样例 按钮 | 点击 | 下拉：骨科转诊信/全科转录 |
| 样例项 | 点击 | 填充 textarea |
| 输入 textarea | 输入文本 | — |
| 提取事实 按钮 | 点击 | `POST /api/facts/extract` |
| 空状态 | 查看 | Wand2 图标 + "生成的事实将显示在这里" |
| 加载中 | 查看 | 旋转圆环 + "提取中..." |
| 结果区 | 查看 | 主诉/诊断事实/手术事实/排除发现/时间信息/文档概览 |
| 状态标签 | 点击 | 循环切换：已确认→待确认→已排除→已执行→计划中→已讨论 |
| 设置面板 | 查看 | 输出语言选择 |
| 代码面板 | 查看 | SDK 代码 + JSON |
