# EmbeddedAssistantPage

**路由**: `/ai-studio/embedded-assistant` | **定位**: 嵌入助手预览

## 元素
| 元素 | 操作 | 预期 |
|------|------|------|
| 预览标签 + 预览会话标题 | 查看 | 16:9 比例预览卡片 |
| 桌面/移动切换 | 点击 Monitor/Smartphone | 切换视图 |
| 上下文标签 | 点击标签 → 切换 | + 添加新标签 |
| 输入内容/Write something | 点击 | 展开单行编辑器 + Pencil 图标 |
| 语音按钮 🎤（编辑器内） | 点击 | 开始/停止录音 |
| 录音按钮（蓝色胶囊） | 点击 | 同语音按钮 |
| 麦克风源选择 | 点击 | Web内置/Medvoice |
| 转录开关 | 点击 | 显示转录文本 |
| AI 对话按钮 ✨ | 点击 | 弹出 AI 对话窗口 |
| 菜单 GripVertical | 点击 | 重新开始/复制嵌入代码/新窗口打开 |
| 设置面板 | 查看 | 会话/功能/外观/语言 |
| 代码面板 | 查看 | SDK 代码 |
