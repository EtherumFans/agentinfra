# MedicalCodingPage 操作指导书

**路由**: `/ai-studio/medical-coding`  
**定位**: 医学编码——输入临床文本 → LLM 提取 ICD 编码

---

## 布局：75/25 左右分栏

### 左侧主内容

#### 1. 输入卡片（上）

| 元素 | 操作 | 预期 |
|------|------|------|
| **textarea** | 输入/粘贴临床文本 | 14 行，`placeholder="输入临床文本..."` |
| **使用样例** 按钮 | 点击（右上角） | 下拉菜单显示样例列表 |
| 样例列表项 | hover 显示 ✏ 编辑图标 | 点击：加载样例文本；✏：打开编辑模态框 |
| **+ 添加样例** | 点击 | 打开空白编辑模态框 |
| **开始编码** 按钮 | 点击 | 调用 `POST /api/reviews`，显示结果 |

#### 2. 编辑样例模态框

| 元素 | 操作 | 预期 |
|------|------|------|
| 名称 input | 输入样例名称 | — |
| 文本 textarea | 输入临床文本 | 8 行 |
| 删除样例 | 点击 | 从列表移除 |
| 保存 | 点击 | 写入 localStorage `icoder-medical-coding-samples` |

#### 3. 输出区（下）

| 状态 | 显示 |
|------|------|
| 空 | 🏥 图标 + "智能编码" + "输入临床文本开始分析" |
| 加载中 | 旋转圆环 + "分析中..." |
| 结果 | 诊断卡片（名称+编码+证据+状态标签）+ 手术卡片 + 备选编码 |

---

### 右侧设置面板

| 分区 | 元素 | 操作 |
|------|------|------|
| **编码系统** | 多选下拉 | 勾选编码系统 + "完成"按钮关闭 |
| **置信度阈值** | 滑块 | 0.0-1.0 |
| **展开结果** | 开关 | 控制备选编码显示 |
| **System Prompt** | 点击编辑 | 打开提示词编辑器 |
| **包含/排除编码** | 按钮 → 对话框 | 添加编码筛选 |

---

## 操作流程
1. 选择/输入临床文本
2. 选择编码系统（默认 ICD-10-CN）
3. 点击"开始编码"
4. 查看诊断/手术编码结果
5. 可点击状态标签循环切换（已确认→待确认→已排除...）
