# AgentsPage

**路由**: `/ai-studio/agents` | **定位**: 智能体管理

## 元素
| 元素 | 操作 | 预期 |
|------|------|------|
| 我的AI智能体/预置AI智能体 | 点击标签 | 切换列表 |
| 搜索框 | 输入 | 按名称/描述筛选 |
| 用例筛选（预置） | 点击标签 | 编码/医保/质控/文书/急诊/护理/药学 |
| 创建者筛选（我的） | 选择 | 下拉搜索 |
| **创建智能体** 按钮 | 点击 | 侧滑面板 |
| 智能体行 | 点击 | 跳转 AgentDetailPage |
| 删除按钮 | hover → 点击 | 确认模态框 |
| 空状态（我的） | 查看 | 渐变动画 + "创建第一个AI智能体" |
| 空状态（预置） | 查看 | 搜索图标 + "未找到匹配的智能体" |

## 创建面板
| 元素 | 操作 |
|------|------|
| 名称 | 输入 |
| 描述 | 输入 |
| 分类 | 选择下拉 |
| AI生成 System Prompt | 点击 → LLM 生成 |
| 专家绑定 | 内联选择器 |
| 使用模板 | 点击 → 模板选择器 |
| 创建 | 点击 → POST /api/agents |
