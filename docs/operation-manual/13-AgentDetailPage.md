# AgentDetailPage 操作指导书

**路由**: `/ai-studio/agents/:agentId`  
**定位**: 智能体详情——左侧对话区 + 右侧设置/代码/真实运行历史面板

> 项目 Agent 使用显式生命周期（`draft` / `published` / `archived`）。只有 `published` 且后端判定可运行时，页面才允许测试或对话；“运行记录”只展示后端已经持久化的 Run History，不生成或暗示金标准准确率。

## 左侧：对话区

### 0. Runtime 与生命周期栏

| 元素 | 操作 | 预期 |
|------|------|------|
| **状态与版本** | 查看 | 项目 Agent 显示后端返回的生命周期状态和语义版本 |
| **发布** | 点击 | 将草稿发布为可运行状态 |
| **归档** | 点击 | 停止运行并锁定设置编辑 |
| **恢复** | 点击 | 将已归档 Agent 恢复到已发布、可运行状态 |
| **测试** | 点击 | 仅在生命周期允许运行时打开测试面板 |
| **运行记录** | 点击 | 打开真实、持久化的运行历史；不计算模拟评估分数 |

### 1. 消息列表

| 元素 | 说明 |
|------|------|
| 用户消息 | 右对齐，`bg-primary text-primary-foreground` 蓝色气泡 |
| 智能体消息 | 左对齐，`bg-muted text-foreground` 灰色气泡 |
| 加载动画 | 3 个跳动圆点（Assistant 思考时） |
| 错误消息 | 显示 `错误：{消息}` |

### 2. 文档附件卡片

| 元素 | 操作 | 预期 |
|------|------|------|
| **FileText 图标** | 查看 | 病例附件标识 |
| **病例标签** | 查看 | 如 "腰椎间盘突出症" |
| **编辑按钮** ✏ | 点击 | 弹出模态框编辑病例内容 |
| **移除按钮** ✕ | 点击 | 移除附件卡片 |
| **病例内容** | 查看 | 显示前 500 字，超出滚动 |

**位置**: 输入框上方，`bg-background rounded-xl shadow-sm ring-1 ring-border/20`

### 3. 消息输入区

| 元素 | 操作 | 预期 |
|------|------|------|
| **文本输入框** | 输入文本 | `placeholder="输入问题...（回车发送）"` |
| **发送按钮** ▶ | 点击或 Enter | 发送消息，开始 SSE 流式对话 |
| **添加文件/JSON** | 点击 📎📊 | 切换输入模式 |

**快捷键**: `Enter` 发送，`Shift+Enter` 换行  
**禁用**: 输入为空、Agent 未发布或已归档时不可发送；生命周期禁用原因由页面提示。

### 4. 快速操作按钮

| 按钮 | 操作 | 预期 |
|------|------|------|
| **你能做什么？** | 点击 | 发送 "你能做什么？请描述你的能力..." |
| **建议提示** | 点击 | ①附加默认病例卡片 ②按智能体类型自动生成 prompt 填入输入框 |

**建议提示生成的 Prompt 模板**:

| 智能体能力 | 生成的 Prompt |
|-----------|--------------|
| 索引/索引导航 | `请遍历ICD-10字母索引，为"腰椎间盘突出症"提供主要候选编码及相关子术语。` |
| 提取/诊断 | `请从以下病例中提取所有诊断并分配ICD-10-CN编码，提供证据引用。` |
| 校验/验证 | `请验证以下病例编码的准确性，检查是否存在编码规则违反或冲突。` |
| 合规/护栏 | `请评估以下病例编码组合的合规性，按医保结算清单规范逐项检查。` |
| 规则/解释 | `请解释以下病例中选用的ICD编码依据，并评估是否存在更合适的编码方案。` |
| 其他 | `请分析以下病例并提供ICD-10-CN编码建议，说明编码依据和证据支持。` |

## 右侧：设置/代码面板

### 设置标签页

| 分区 | 元素 | 操作 | 预期 |
|------|------|------|------|
| **基本信息** | 智能体名称 | 输入（≤50字） | 实时显示计数 `(25/50)` |
| **System Prompt** | 点击区域 | 点击 | 打开 `EditSystemPromptModal` 全屏编辑器 |
| **专家** | 专家列表 | hover 显示 ✕ | 点击 ✕ 移除专家 |
| | 空白状态 | 虚线边框 + Wrench 图标 + "未绑定专家" | |
| | **添加专家** | 点击 | 打开 `ExpertLibraryModal` |
| **删除** | 点击 | 弹出确认模态框 | |
| **保存** | 点击 | 调用 `PUT /api/rest/v1/agent_definitions/:id` | 已发布 Agent 的实际配置变更自动提升 patch 版本；归档状态不可编辑 |

### 运行记录面板

| 元素 | 数据来源 | 说明 |
|------|----------|------|
| **刷新运行记录** | 后端 Run History API | 重新读取当前 Agent 已持久化的运行 |
| **运行条目** | `run_id`、`status`、`created_at`、`runtime_mode`、`latency_ms` | 仅显示实际运行元数据 |
| **空白状态** | 后端返回空列表 | 显示“尚无已持久化的运行记录” |

该面板不是临床准确率评估。独立金标准、人工 reviewer 和统计学验证尚未接入时，页面不会展示伪造的 accuracy、通过率或 CSV 评估结果。

### 代码标签页

| 格式标签 | 内容 |
|---------|------|
| JavaScript (SDK) | `import iCoDer...` + `runs.runText`，使用当前项目 Agent ID |
| Python (SDK) | `from icoder_sdk import...` + `runs.run_text` |
| curl | tenant-bound Bearer token + `Idempotency-Key` + `/api/v1/agents/{id}/run` |
| JSON Config | 与 curl 相同的 endpoint/header/body 合同 |

**复制按钮**: 右上角 Copy 图标 → 绿色 Check 2 秒

## 操作流程

### 流程 1：对话
1. 进入页面 → 加载智能体数据 + 会话记忆
2. 在输入框输入 → 按 Enter 或点击发送
3. 等待 Assistant 流式回复（SSE）
4. 可继续追问

### 流程 2：使用建议提示
1. 点击 **建议提示** 按钮
2. 文档卡片出现在输入框上方（病例名 + 内容）
3. 输入框自动填入对应的操作指令
4. 可编辑或移除附件卡片
5. 点击发送 → Agent 收到 `[附件：病例名]\n病例全文` + prompt

### 流程 3：编辑设置
1. 确认 Agent 不是 `archived`；如已归档，先点击“恢复”
2. 修改智能体名称
3. 点击 System Prompt 区域 → 编辑 → 保存
4. 点击"添加专家" → 浏览/选择 → 确认
5. 点击"保存"；已发布 Agent 的有效变更会自动提升 patch 版本

### 流程 4：查看代码
1. 点击 **代码** 标签
2. 切换语言 Tab（JS/Python/C#/JSON）
3. 点击复制按钮

### 流程 5：发布、归档与恢复

1. 草稿点击 **发布** 后才允许运行
2. 已发布 Agent 点击 **归档** 后，聊天、测试和设置保存立即禁用
3. 已归档 Agent 点击 **恢复** 后回到已发布状态
4. 生命周期变更由后端持久化并写入审计日志，页面只显示后端返回状态

### 流程 6：查看真实运行历史

1. 点击顶部 **运行记录**
2. 点击 **刷新运行记录**
3. 核对运行 ID、状态、时间、运行模式和延迟
4. 如无记录，页面保持诚实空白状态，不生成模拟评估结果

## 错误处理

| 场景 | 预期 |
|------|------|
| 智能体不存在 | 显示 "未找到智能体" + 返回按钮 |
| SSE 流中断 | 显示 "错误：HTTP xxx" |
| 草稿或归档 Agent 发起运行 | 前端禁用；即使绕过前端，HTTP/A2A 后端仍以 `agent_not_published` 失败关闭 |
| 归档 Agent 保存设置 | 保存按钮禁用，并提示先恢复 Agent |
| 保存失败 | 显示后端或网络错误，不把失败状态呈现为已保存 |
| 删除确认 | 模态框："确定删除 xxx？此操作不可撤销" |
