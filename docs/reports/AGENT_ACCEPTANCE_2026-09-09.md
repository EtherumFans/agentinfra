# 智能体接入验收闭环 · 2026-09-09

## 交付

接入页面可选择用途及正文/JSON 输入方式，校验非空 text 字段，并生成对应配置与请求示例。延用已有发布版本选择，固定版本及配置摘要；展示运行耗时、版本证据及运行记录入口。新增第三方验收步骤及回调模块下载。

可下载的第三方应用新增验收报告导出、合成异步任务、任务/回调状态刷新、签名校验和 SQLite 持久去重。报告区分用户登录检查、机器凭据检查和回调收到，避免把页面调用成功当作外部客户端已验收。同步网络超时不自动重试，异步提交保留幂等键。

## 真实 HTTP 端到端测试

`backend/tests/test_api/test_third_party_acceptance.py` 启动两个独立的回环 TCP HTTP 服务：iCoDer API 和下载的第三方应用。第三方业务调用使用真实 OAuth 令牌，经过正常权限、发布快照、数据库任务和工作进程；没有将上游 API 替换成固定 HTTP 响应。

验证通过：

- 第三方本地登录保护、跨来源请求拒绝、空输入拒绝。
- 首次调用成功，版本为 1.0.0，返回真实运行标识；报告记录耗时。
- iCoDer 发布新版本后，第三方固定配置仍执行原 1.0.0。
- 错误配置摘要被 409 拒绝；未授权用途被 403 拒绝。
- 异步重复提交使用相同键返回同一任务；正常工作进程完成执行。
- 首次回调模拟 503，第二次通过真实 HTTP 到接收器，通知状态 delivered、尝试次数 2。
- 回执持久化成功；重复通知不重复写入；篡改与过期签名被 401 拒绝。
- 撤销专用客户端后，第三方检查无法再获得授权。
- 额外定向测试验证网络超时返回 504，且没有自动重复执行。

证据：`artifacts/product-review-2026-09-07/third-party-acceptance.json`。只保留元数据，不保留服务端密钥。

## 范围说明

模型采用确定性合成实现，验证的是产品接入链路，不是临床输出质量。两个 HTTP 服务在测试进程中独立监听回环端口。回调白名单仍登记 HTTPS 测试域名；仅测试发送函数把该已登记地址映射到回环接收器，以验证真实字节传输、验签和去重。产品的公网 HTTPS 要求、SSRF/DNS 限制未被放宽。本次不宣称完成公网 TLS、医院网络或真实第三方部署验收。

测试数据库为隔离 acceptance-tests.db；服务关闭后测试凭据不作为运行演示继续使用。产品审核入口仍使用此前独立 remediation-ui.db。没有触及真实患者资料或生产发布。
