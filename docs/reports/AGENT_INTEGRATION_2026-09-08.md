# 智能体便捷集成：第一轮实现

> 后续更新：下述“当前配置绑定”及复制即发布是本轮历史记录，现已由[智能体发布版本管理](AGENT_RELEASES_2026-09-08.md)替代。新建与复制产生草稿，发布保存独立快照，历史版本可以固定调用。

入口：自建智能体详情 → 集成。只有当前组织内已发布的自建智能体可以取得集成配置。向导提供配置下载、本地用户服务端示例、网页/React/API 代码、合成文书运行检查和运行记录链接。

## 接入方式

用户网页调用自己服务端的 `/icoder/run`。示例服务端读取专用 OAuth 凭据，取得短期令牌，固定智能体、版本、配置摘要和用途后调用 iCoDer。浏览器不接收 OAuth 客户端密钥或令牌。示例使用本机 Basic 登录和来源检查，仅监听 127.0.0.1:13010；部署时应接入用户系统自身的身份与授权。示例不会自动写回病历或重试任务。

在 API 客户端页面配置 `api:write`、目标智能体 ID 和 `quality_improvement` 用途，凭据只写入下载到用户服务端的配置文件。撤销客户端后旧令牌的后续调用被拒绝。网页完成事件为 `icoder:completed`，React 示例通过 `onCompleted` 接收结果；失败不触发完成回调。

## 版本语义

当前系统修改已发布智能体会更新其配置并递增版本，并没有独立历史发布快照。因此本轮实现的是明确的“当前配置绑定”，不能声称支持历史版本托管。

集成清单包含 `version` 和 `configuration_digest`。Run 请求通过 `expected_agent_version` 与 `expected_configuration_digest` 校验；仅提供一个字段会拒绝，版本或智能体配置变化返回 409。旧调用不会静默切换到新配置，需重新审核并获取绑定。模型、Expert 内容、工具和知识源的独立版本不由该摘要冻结。历史快照、完整依赖锁定及无中断升级仍是后续任务。

旧嵌入助手的 React 示例已修复组件加载竞态，并补充卸载取消与初始化错误事件。新的集成向导通过用户服务端固定参数，不依赖旧组件移除 `@version` 的兼容路径。

## 验证与限制

新增测试覆盖发布配置、跨组织不可见、真实用户 JWT、OAuth 客户端执行、用途拒绝、配置变化拒绝、撤销访问、运行记录读取，以及下载示例到实际授权/Run 接口的链路。只有模型输出在测试中使用合成响应，测试不代表真实模型的文书质量。另验证了示例未登录拒绝、外部来源拒绝、浏览器不能替换固定参数和 OAuth 凭据不返回浏览器。

后端专项回归 42 项通过（集成、代理、生命周期、七阶段桥接、幂等、OAuth、项目克隆运行）；前端 28 个文件、184 项测试通过；类型检查和构建通过。构建产物及服务端示例已同步本地审查服务。

证据：`artifacts/product-review-2026-09-07/integration-tests.log`、`integration-regression.log`、`integration-frontend-tests.log`、`integration-build.log`。

用户随后明确授权创建本地普通测试账户，已完成注册、登录、文书模板副本创建、集成入口、真实规则执行与运行记录跳转的浏览器检查。当前模板复制入口直接产生已发布副本（1.1.0），不能把该路径描述为手动草稿发布验收。

本次 UI 验收发现并修复三个问题：注册校验数组被直接渲染导致白屏；本地 13000 审查端口未纳入运行服务的来源配置；窄屏主内容被侧栏和最小宽度挤出。来源配置仅调整本地启动环境，未放宽产品默认允许列表。集成检查输入新增可编辑区域。589px 下主内容宽度和 scrollWidth 均为 589px，导航通过工具栏展开。

合成输入先返回 INPUT_REQUIRED，带章节输入返回 PARTIAL，均保留人工复核要求；运行记录正常显示规则模式与复核信号。该结果只证明实际调用与结果展示，不能当作临床质量通过。成功业务回调的自动化合同仍以合成模型测试为证据。

补充验证：29 个前端文件、186 项测试通过，类型与构建通过。截图：`integration-ui-desktop.png`、`integration-ui-narrow.png`、`integration-ui-trace.png`；日志：`integration-ui-tests.log`、`integration-ui-build.log`。真实模型配置、生产主机认证接入、历史发布快照和独立依赖版本管理仍未在本轮关闭。
