# 智能体运行运营台 · 2026-09-09

## 功能

入口 `/operations`，侧栏新增“运行运营台”；智能体交付导航可带 agent_id 进入对应范围。支持近 1/7/30/90/365 天、智能体 ID、发布版本、客户端 ID 精确筛选，手动刷新和可选 15 秒自动刷新。

展示执行量、成功率、平均耗时、失败及其他状态；异步状态与通知状态分开展示。按智能体名称/标识、版本、客户端汇总。明细服务端分页，每页 20 条；仅失败筛选作用于明细，不改变总指标。

失败按认证、权限、版本/依赖、超时/结果不确定、工具、模型及其他分类，并给出排查建议。运行证据链接继续使用原有访问控制。错误分类依据已记录错误码，不展示原始异常、输入、输出、任务载荷、回调地址或凭据。

支持取消排队和仅重试失败通知。服务端在当前组织内校验用户角色，原子更新允许的状态并写入审计；并发取消仅一次成功。中断或结果不确定的执行不会提供直接重跑按钮。重试通知不更改任务结果，也不触发重新执行。

## 权限与口径

- 组织 owner/admin 查看并管理组织内运营元数据；其他成员仅查看、处理自己的用户任务。机器凭据不能登录该运营 API。
- 所有查询明确限定组织，并排除运行记录中被隔离或归属不明的分类；不存在/无权访问的任务均返回 404。
- 成功率为成功/(成功+失败)，取消、运行中及其他状态不计入分母。无完成样本时显示空值，不显示虚假的 100%。耗时取已成功或失败执行的已记录 latency_ms 平均值。
- 执行记录包含异步执行，不能再与任务数相加。队列与回调统计按所选时间内创建的任务计算，旧任务需扩大时间范围。
- 汇总最多显示调用量前 100 组，明确提示截断；总指标仍基于全部匹配记录。数据来自实时查询，不是报表快照，不保证并发写入期间多项指标处于同一事务快照。
- 在生成运行记录之前被拒绝的认证/权限请求，不在本页统计；全量网关拒绝事件及告警规则属于后续扩展。执行成功也不等于专业质量审核通过。

## 验证

审查目录：`artifacts/product-review-2026-09-07/`。

- SQLite：12 项通过（`operations-backend.log`），含运营聚合与分页、过滤、组织隔离、成员可见性、并发取消、审计、仅重试通知，以及既有异步任务和第三方真实 HTTP 全链路测试。
- PostgreSQL 17.11 受限应用角色：2 项运营定向测试通过（`operations-postgres.log`）。修正了运行表无时区 UTC 与任务表时区类型的差异，以及错误分类 GROUP BY 参数表达式复用；无需数据库迁移。
- 前端：40 文件、214 项通过（`operations-frontend.log`）；TypeScript 与生产构建通过。构建仍有既有主包大小建议，后端 HTTP 测试仍有依赖弃用提示。
- 固定合成数据：25 条执行，20 成功、5 失败、成功率 80%、平均 180ms；下一页 5 条且不重复。隐藏归属分类、100 天前记录和其他组织均不进入默认指标。
- 第三方真实 HTTP 场景同时核对运营台的 completed 任务、delivered 回调和对应 run_id；汇总组数量之和与执行总量一致。元数据证据在 `third-party-acceptance.json` 的 operations_statistics 中。模型采用合成实现，不代表真实医疗质量验收。
- 本地产品页面成功读取既有审核组织的 12 条执行及 4 个异步任务；该数据库仅供合成审核。页面保留供用户查看。
