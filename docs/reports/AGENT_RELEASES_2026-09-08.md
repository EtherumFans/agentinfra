# 智能体发布版本管理

入口：自建智能体详情 → 草稿与版本。适用于当前组织的自建智能体及模板副本。

## 已实现

- 新建及模板复制产生草稿；保存修改不改变线上运行配置。
- 发布保存独立的定义与已解析运行配置快照，自动递增版本。重复发布相同草稿不新增版本；并发发布通过事务锁串行化。
- 默认调用读取默认发布快照。集成页可以选择历史版本，通过版本和配置摘要固定调用；后续发布不使旧绑定失效。
- 历史版本可以设为默认或回滚，不覆盖当前草稿。回滚后再次发布按全部历史版本递增，避免重用版本号。
- 普通组织用户可以调试已保存草稿，返回 `draft_preview` 和执行版本标记；OAuth 客户端禁止调试草稿。
- 归档后禁止运行；发布历史、激活操作及固定版本调用保持组织隔离。不存在的版本返回 404，摘要不匹配返回 409。
- 旧系统已发布定义在首次修改或读取发布管理时保留为历史基线。无法恢复升级前已经被覆盖的历史内容。

## 验证

后端 43 项专项测试通过：发布生命周期、历史固定版本、草稿预览、回滚与再次发布、并发发布、JWT/OAuth 权限、跨组织隔离、克隆运行、集成代理、幂等及迁移保护。前端 30 个文件、188 项测试通过，类型检查和构建通过。

普通测试账号浏览器验收：已有 1.1.0 副本保存草稿后版本未变；草稿调试返回 `executed_agent_version: draft`；发布生成 1.1.1；回滚默认版本至 1.1.0 后保留修改后的草稿与两个历史版本。合成资料返回规则引擎 INPUT_REQUIRED，保留人工复核要求。测试不证明真实模型的医疗质量。

证据位于 `artifacts/product-review-2026-09-07/`：`release-tests.log`、`release-frontend-tests.log`、`release-build.log`、`releases-desktop.png`、`releases-narrow.png`。589px 窄屏下主区 clientWidth 与 scrollWidth 均为 589px，无横向溢出。

## 部署与边界

新增迁移 078，生产数据库需迁移后启动。迁移包含 PostgreSQL 租户 RLS；本次验证使用隔离 SQLite，未进行真实 PostgreSQL 部署验收。有历史数据时降级迁移拒绝删除发布表。

快照冻结智能体定义与发布时解析的运行配置，不冻结外部模型权重、工具程序、知识服务或应用执行引擎。仅修改外部依赖而不修改智能体定义，不会自动生成新发布版本。本轮没有灰度流量、环境晋级或完整外部依赖锁定。
