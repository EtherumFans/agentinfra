## 实现结果

1. 浏览器会话：刷新凭据转入 HttpOnly cookie；短期访问凭据仅驻留内存；登录、刷新、切换组织、退出统一管理；校验 Origin、自定义请求头与 HTTPS。新增可撤销会话表及 084 迁移。退出后访问与刷新重放均被拒绝，不撤销其他会话。WebSocket 在连接及后续消息上校验会话撤销。
2. 异步调度：组织轮转、单进程及组织并发上限、独立回调池、空闲退避。数据库领取与中断证据保持不变；慢回调不阻塞执行池。
3. 对话与记忆：组织历史按服务端分页读取，可预览并恢复原上下文；持久记忆检索限定当前用户、组织、智能体、用途和有效授权。显示匹配来源、扫描窗口和实际检索方式，可继续检索较早窗口。正文不写入浏览器存储。
4. 依赖影响：组织管理员可查询绑定草稿、引用该依赖的发布版本、智能体待完成任务和授权客户端。运行配置中的模型、工具名称可作为登记候选；只提供建议，不自动证明外部版本真实性。
5. 结构与流程：评测及依赖路由从智能体 CRUD 模块拆分；复用会话刷新、历史消息投影与交付导航。详情、版本、评测、集成、任务及依赖页面提供连续入口，展示实际评测状态、默认版本与未发布修改。

测试数据库原先未继承 SQLite WAL/超时/外键配置，已沿用产品连接配置；旧发布测试改为真实注册用户以满足外键。队列测试限定自己创建的组织，避免处理旧测试积累的任务。较早记忆测试明确设置早期时间并使用完整的合成偏好文本：单独的短中文关键词可能被既有脱敏规则当作姓名；未放宽脱敏规则。
