# 真实模型业务评测与发布验收

## 交付内容

- 发布评测页新增文书处理、医学编码、质量审核三个固定版本套件，每类两个合成样例。服务端提供样例并检查摘要，客户端不能用自定义弱规则替代业务验收。
- 输出按 JSON 对象、字段、类型和值逐项检查，拒绝额外字段、重复键和非标准数值。评测报告保存检查结论、运行链接、输出摘要及模型用量，不复制原始输入输出。
- 业务评测要求运行记录具有真实网关调用和完整 Token 证据；组织模型连接还要求实际提供者、模型与配置匹配。模拟输出或无调用证据不能通过。
- 发布管理可配置指定业务套件。启用后要求当前草稿的最新匹配报告通过，且由组织所有者或管理员明确接受。复核意见必填；决策独立追加保存，并使用上一条决策 ID 防止覆盖并发复核。
- 报告绑定草稿、依赖、运行配置及模型连接版本；更改配置后旧证据失效。新失败报告、拒绝复核、跨组织访问和普通成员复核均被相应门禁拦截。
- 前端显示固定样例、逐项检查、实际模型、Token、运行记录、报告下载和人工复核入口。已配置业务套件时默认选择该套件。
