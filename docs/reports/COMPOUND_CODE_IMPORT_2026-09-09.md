# 组合编码导入兼容性

Excel 评测导入此前只允许字母、数字、点和连字符，导致包含加号和星号的组合标签无法导入。现支持以加号连接的非空编码片段，以及各片段末尾的可选星号，保持标签大小写、前导零和顺序。组合标签是一个预期答案，不拆分或改写医学含义。

非法首尾加号、连续加号、片段内部星号、重复星号、公式和其他非法字符仍被拒绝。主要编码列仍最多一个标签。前端格式说明同步更新。此规则仅校验导入语法，不替代编码字典或医学审核。

验证：

- PostgreSQL 后端回归 46 项通过，覆盖预览、加密保存、批量任务、业务评测、发布门禁和第三方接入。
- 前端导入测试 5 项通过，TypeScript 检查通过。
- 本地服务重启后，以合成 XLSX 通过真实 HTTP 预览接口验证组合标签保留。
- 用户训练文件全量只读验证：1800 条均可解析，原先 99 条中的 102 个组合标签完整保留；四类标签逐行与原始文件一致，文件哈希未变化。
- 原始训练文件未保存到产品数据库，未调用模型。本地敏感信息复核明细留在忽略的审查目录，不进入产品源码。

测试保留既有的两项 websockets 弃用警告。
