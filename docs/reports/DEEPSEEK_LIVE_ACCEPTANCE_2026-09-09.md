- 三次智能体真实模型调用成功，所有响应都有实际模型标识、Token 用量、非空正文和正常结束标记，无模拟降级。

- 异步任务完成；幂等重复提交未增加执行次数。

## 测试调整与边界

首次完整试跑在异步轮询读取异常响应时中断；原测试直接读取字段，缺少 HTTP 状态断言。已增加状态断言，并将真实模型模式的轮询间隔设为 2 秒，完整复测通过。首次异常的具体 HTTP 状态未被原断言保留，不能据此断定是限流或数据库问题。

测试默认继续使用合成模拟模型。只有显式设置 `ICODER_LIVE_DEEPSEEK_ACCEPTANCE=1` 才启用真实模型；密钥由进程环境注入，不进入源码或报告。真实模式最多验证五次成功模型调用，单次输出上限 2048 Token。

本报告验证接入与运行链路，不代表医学编码准确率、文书质量或医疗审核质量达标。业务用例使用合成资料和测试智能体。公网回调地址在测试中映射到本地接收服务，因此生产网络、TLS、生产数据库和云端秘密管理尚需独立验收。现有本地 UI 服务未切换为 DeepSeek。
