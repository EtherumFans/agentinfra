# 评测集保存与批量运行验收

日期：2026-09-09

## 已交付

智能体的“发布前质量评测”页面新增“评测集与后台批量运行”。可以保存编辑中的样例，或直接导入完整 XLSX / JSON 文件。每个版本最多 2000 条，文件导入不调用模型。Excel 沿用病历编码训练集字段映射，输入资料与预期编码分开处理；非法记录会阻止保存，避免静默丢行。

评测集区分训练、验证和验收用途。每次追加生成不可变的新版本，重新进入待审核状态；版本更新和审核使用并发检查。组织管理员审核接受后才能运行。用途标签不自动执行数据去重或训练与验收数据污染检测。

样例通过 EncryptedPHIJSON 加密保存，三个新表均启用并强制执行 PostgreSQL 租户 RLS。版本可下载全部样例，也可复制前 10 条回编辑区。

后台批次绑定评测集版本与当前已保存草稿摘要，提供幂等提交、持久队列、历史批次、逐项结果分页、未通过项筛选、字段匹配统计、模型证据和运行记录入口。每个组织串行执行样例；默认全局并发为 2。

取消只停止尚未开始的样例，正在运行的样例收尾。重试仅覆盖执行失败或中断项，不重跑执行成功但规则未通过的样例。每次尝试保留开始和结束事件。配置变化后需要创建新批次。

工作进程每 30 秒续租，租约为 90 秒。未开始的持久任务可在重启后继续；异常退出导致执行结果不确定时，过期任务转为中断并等待手动重试，避免自动重复调用模型。旧执行者不能覆盖重新认领后的结果。

字段统计使用指定预期值的精确 JSON 匹配（数组包含顺序），只表示这些样例的检查结果。批量产生的单例报告明确标记，不能作为独立报告绕过发布验收门禁。当前批量功能评测已保存草稿，不进行批量基线对比或自动发布。页面显示最近 20 个批次。

- 前端：15 项通过；TypeScript 检查及生产构建通过。构建保留既有的大 chunk 提示，后端有两项 websockets 弃用提示。

## 使用步骤

1. 打开智能体的评测页面，填写评测集名称并选择数据用途。
2. 保存编辑中的样例，或使用“导入完整文件并保存”上传 XLSX / JSON。
3. 核对脱敏资料与预期结果，由管理员填写意见并接受该版本。
4. 点击“开始后台批量评测”，随后可离开页面并返回查看历史批次。运行会使用当前组织配置的模型并产生相应 API 费用。
5. 检查未通过样例及运行证据，必要时重试执行失败项，或修订数据生成新版本。

用户提供的 `E:/iCoDer Agent/data/train.xlsx` 未被自动持久导入或发送给模型。本次实际模型验收仅使用固定合成样例。
