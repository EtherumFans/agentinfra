# 评测样例导入、填写模板与合成示例

入口：智能体 → 发布前质量评测 → 准备业务评测样例。

## 已实现

- 下载 JSON 填写模板，选择文书处理、医学编码、质量审核合成示例并下载或预览。
- JSON 支持样例数组和带 `cases` 的套件对象，支持 UTF-8 BOM。校验重复标识、正文、检查规则、预期对象、未知字段和大小；失败不替换当前编辑内容。
- 预览后点击“使用这组样例”才替换编辑内容，切换到自定义评测并清除基线选择。不会自动执行模型或修改发布门禁。
- 表单支持预期模型 JSON，保留数组、布尔值、空值和对象，导入后可继续编辑与导出。
- XLSX 按起始记录与条数预览，每次 1–10 条。自动识别唯一包含病历正文和四类编码答案列的数据表。病案标识不进入样例；答案列只映射到预期 JSON，不拼入模型输入。
- 主要编码映射为字符串或 null，其他编码映射为字符串数组；保留文本编码中的前导零。拒绝数值编码和公式，提示检查特殊空值标记。错误行明确显示，界面拒绝静默丢弃错误行后部分导入。
- JSON 上限 1 MB；Excel 上限 10 MB、解压后 64 MB，限制 ZIP 条目，不支持宏及外部链接。Excel 接口验证组织内智能体归属。
