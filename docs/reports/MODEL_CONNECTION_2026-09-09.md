# 极简模型连接配置

入口：`/models` 页面顶部的“模型连接”。首批支持 DeepSeek V4 Flash / V4 Pro。

## 使用方式

组织所有者或管理员选择模型、填写 API Key，点击“测试并启用”。服务端仅发送固定合成文本，测试通过后才保存和启用；失败保留原配置。再次编辑时密钥留空表示保留，页面从不回显密钥。支持恢复组织原有默认模型选择。

配置只作用于当前组织，经模型网关运行的智能体下一次调用即时生效，不需要重启。不同组织不会共享已保存凭据。部署已有的数据外发策略仍优先；若部署禁止外部模型，按钮不可用且 API 拒绝调用。独立医疗工具中绕过统一模型网关的旧服务配置不在此次变更范围内。

## 实现与安全边界

- 新增 `model_connections` 表及 Alembic 085，PostgreSQL 启用并强制组织 RLS。
- 密钥使用 Fernet 加密，密文绑定组织 ID；加密密钥由部署稳定的 `ICODER_SECRET_KEY` 经用途隔离派生。该部署密钥须持久保管；更换后需重新录入连接密钥，不可使用临时随机开发密钥保存凭据。
- 接口不接受任意服务地址，只使用 DeepSeek 官方 HTTPS 地址。
- 连接测试最多 256 输出 Token、单次尝试、35 秒总超时；冷却时间按组织保存在当前服务进程，多副本部署并非共享额度限制。
- 保存与恢复默认采用版本号检查，防止管理员覆盖更新；审计只记录服务商及配置版本，不记录密钥和请求正文。
- 组织配置在请求级解析，动态适配器不进入全局注册表；服务重启、多进程从同一数据库读取配置。
- 修复结果适配器以全局 mock 默认值误判组织真实模型结果的问题；仍拒绝实际模拟结果及降级响应。
- 模型目录展示当前组织的有效模型；模拟默认值不再沿用 DeepSeek 模型名称。
