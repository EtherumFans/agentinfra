# 真实模型用量与估算费用

入口：运行运营台 `/operations`。

## 交付

- 汇总当前筛选范围内观测到的模型网关调用、输入/输出 Token、美元估算费用。
- 执行明细展示实际返回的服务商、模型、多轮调用累计和分模型明细。
- 独立展示有记录/未记录的运行数量、Token 完整记录数量及费用完整记录数量。
- 区分 NULL（未记录）、已报告零值和部分记录。模拟响应不生成真实用量；真实提供者降级后的合成零值不能冒充零消耗。
- 汇总沿用原有组织、成员、智能体、发布版本、客户端和时间过滤；明细“仅失败”选项不改变总指标。
- 请求级收集器只捕获数值与模型标识，不捕获输入、输出或密钥。并发调用隔离；同一运行中的多轮调用累计；流式调用在终态记录一次。
- 新增 Alembic 086，为运行表增加可空模型用量列；历史记录不推测、不回填为零。独立于旧费用字段及产品扣费逻辑。
- 修复历史补写路径隐式采用数据库本地时区的问题，显式使用 UTC，与正常运行开始记录保持一致。

## 口径

“调用”表示通过统一网关观测到的提供者调用，不等于供应商 HTTP 请求计费次数。内部网络重试、无终态的中断、绕过统一网关的旧工具或未写入运行记录的调用，无法据此重建完整账单。记录完整只表示已观测调用的字段完整。

失败也可能产生费用。估算使用网关已有的价格配置和报告值，不是供应商账单或产品积分；没有按此次任务重新定价或换算人民币，不应将旧 `cost_usd` 字段无币种来源的记录混入新汇总。缓存价格、服务商账单对账与历史补录仍是后续独立工作。

嵌套智能体各自保留运行记录，跨层调用不应被用户当作独立账单条目直接重复累加。本次不提供预算拦截或余额控制。
