# macOS 浅色工作台重构

本次按用户更正替代深蓝导航、青绿强调的旧版主题。全局改为 #F5F5F7 背景、白色卡片、#E8E8ED 分组底色和 #0071E3 主色，标题 #1D1D1F、正文 #3A3A3C、辅助文字 #6E6E73。采用系统字体，优先苹方和微软雅黑，移除远程字体请求；按钮 9px、卡片 16px、面板 18px，主要操作采用胶囊形。面板使用透明白色、细边框与轻阴影。

全局外壳增加 76px 品牌栏与 58px 工具栏。共享工作台采用 184px / 自适应 / 316px 三栏，中央为灰色渐变桌面与白色文档，右侧保留可编辑输入和辅助信息。左栏复用已有输入、输出作为目录导航，未虚构产品尚不具备的多页缩略图功能。文书生成、信息提取、语音转写复用该结构；CDI 工作台同步采用三栏容器。文档工作台的全局导航通过工具栏展开，避免同时出现四栏。

## 验证

- TypeScript 检查通过，27 个前端测试文件、181 项测试通过，Vite 构建通过。
- 浏览器在 1440px 下测得品牌栏 76px、工具栏 58px，左右栏分别 184px、316px；主按钮实际计算颜色为 rgb(0, 113, 227)。
- 920px 下左栏隐藏；760px 和 589px 下内容区在上、辅助区在下。三个尺寸均未出现页面横向溢出。
- 截图使用真实 WorkbenchLayout 组件和合成输入，品牌栏为采用产品样式的预览外壳；不执行业务请求，不等同于已登录产品的完整截图或业务流程验收。

证据位于 `artifacts/product-review-2026-09-07/`：`macos-ui-desktop.png`、`macos-ui-920.png`、`macos-ui-narrow.png`、`macos-ui-tests.log`、`macos-ui-build.log`。预览入口为该目录下 `ui/macos-layout-check.html`，仅用于本地诊断，不属于产品路由。
