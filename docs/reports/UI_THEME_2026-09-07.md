# 医疗工作台 UI 主题优化

> 已被用户于 2026-09-08 撤销。当前实现和验收结果以 [macOS 风格重构记录](UI_MACOS_2026-09-08.md) 为准；下文仅保留历史记录。

已将产品主题应用为用户指定的配色：背景#F3F6FA、白色卡片、深蓝导航#172A40、青绿主色#177C72、主文字#21334B、辅助文字#7A8797、细边框#E6EBF1。浏览器计算样式已核对背景、卡片、导航与主按钮的RGB值，均精确对应。

全局卡片圆角10–12px、按钮基础圆角6px；状态色为低饱和绿、蓝、琥珀与红棕。既有语义色类统一继承新配色，弹窗阴影统一减轻。标题与品牌字体统一无衬线，保持原有图标系统；增加清晰键盘焦点与减少动态效果偏好支持。深色模式沿用蓝灰、青绿体系。

导航文字改为深蓝底上的浅色层级，增加通知与账户菜单的可访问名称，移除“暂无新通知”时仍显示的红点。

验证：TypeScript通过、181项前端测试通过、最终Vite构建通过。已浏览真实未登录页面，并检查1440px桌面与589px窄屏的独立主题样张。样张只验证视觉规范，明确标注“非业务页面”，不代表已完成登录后业务工作台验收。

截图位于artifacts/product-review-2026-09-07：ui-theme-desktop.png、ui-theme-narrow.png（设计样张）、ui-theme-login.png（真实登录页）；构建和测试日志为ui-theme-build.log、ui-theme-tests.log。
